# Zawed Supply — منصة توريدات المكاتب (B2B)

منصة توريد مستلزمات مكتبية للشركات والمنظمات في السودان (نحن **المورّد**، لسنا سوقاً
وسيطاً). العملاء يطلبون من كتالوجنا ونحن نُنفّذ، والدخل من هامش الربح + عقود توريد شهرية.

> B2B e-procurement platform for office supplies in Khartoum, Sudan. Arabic-first
> (RTL) with an English toggle, built for ~78% inflation, a depreciating SDG, and
> intermittent low-bandwidth connectivity.

## المبادئ المعمارية (تفرضها ظروف السوق)

- **لا يُخزَّن أي سعر نهائي بالجنيه أبداً.** يُحسب لحظياً:
  `التكلفة بالدولار × (1 + هامش الربح) × سعر الصرف`، ثم يُطبَّق أفضل خصم.
- **لقطة السعر:** عند إنشاء عرض السعر أو الطلب تُجمَّد قيمة الوحدة وسعر الصرف على البنود،
  فالمستندات التاريخية لا تتغيّر عند تحرّك سعر الصرف.
- **الأسعار تُحسب على الخادم فقط.** العميل لا يستطيع إرسال سعر — دوال قاعدة البيانات تعيد
  تسعير كل بند، وسياسات RLS تمنع الكتابة المباشرة على بنود الطلب.
- **يتحمّل ضعف الشبكة:** تسعير الكتالوج كله في استدعاء واحد، تخزين مؤقت يبقى بعد إعادة
  التحميل، غلاف يعمل دون اتصال (service worker)، و**طابور للطلبات** يُرسل عند عودة الاتصال.
- **موجّه للأجهزة الضعيفة:** حزمة الدخول **~122 KB مضغوطة**؛ كل الشاشات الثانوية ومولّد
  الـ PDF مفصولة (code-split) وتُحمَّل عند الطلب فقط.
- **الدفع خارج المنصة:** تحويل بنكي / بنكك / فوري / نقداً / شيك — المنصة تُسجّل الحالة فقط.

## الأدوار (مفروضة عبر RLS وليس إخفاء الواجهة فقط)

`admin` · `sales` · `warehouse` · `customer_admin` · `customer_requester`

ومع ذلك يستطيع تسعير المنتجات عبر دوال `SECURITY DEFINER`.

## التشغيل

### 1) قاعدة البيانات (Supabase)

```bash
supabase link --project-ref YOUR_PROJECT_REF
supabase db push                                        # supabase/migrations
psql "$SUPABASE_DB_URL" -f supabase/seed.sql            # الكتالوج
psql "$SUPABASE_DB_URL" -f supabase/seed_demo_users.sql # مستخدمون تجريبيون
```

أو من **SQL Editor** في لوحة Supabase: الصق ملفات `migrations/*` بالترتيب ثم ملفي البذور.

### 2) الواجهة

```bash
cp .env.example .env      # ضع VITE_SUPABASE_URL و VITE_SUPABASE_ANON_KEY
npm install
npm run dev               # http://localhost:5173
```

> إذا لم تُضبط المتغيّرات، يعرض التطبيق شاشة إعداد واضحة بدل الانهيار.
> بيانات المورّد التي تظهر في ترويسة المستندات تُضبط عبر `VITE_SUPPLIER_*`.

## المراحل الثلاث — مكتملة

### المرحلة 1 — الأساس
كتالوج ببحث عربي يتجاهل التشكيل · تسعير حي حسب الكمية مع جدول الخصومات · سلة · تأكيد طلب
(رقم PO إجباري إن تطلّبته الشركة) · طلباتي · لوحة تحكم بتحذير تقادم سعر الصرف · تحديث سعر
الصرف · إدارة الطلبات.

### المرحلة 2 — المستندات والمالية
- **عروض الأسعار:** منشئ بواجهة بحث، صلاحية 7 أيام مع عدّاد، تعليم كمُرسل، **تحويل إلى
  طلب بالأسعار المجمّدة**، ومشاركة عبر واتساب.
- **الفواتير والمدفوعات:** إصدار الفاتورة من الطلب بتاريخ استحقاق حسب شروط الشركة، تسجيل
  دفعات جزئية بخمس طرق دفع، وسجل المدفوعات.
- **أربعة مستندات PDF ثنائية اللغة:** عرض سعر · فاتورة مبدئية · فاتورة ضريبية · إذن تسليم
  (بخانة توقيع المستلِم)، مع **المبلغ كتابةً بالعربي**.

### المرحلة 3 — التكرار والحوكمة والتقارير
- **الطلبات المتكرّرة:** قائمة دورية محفوظة تُنشئ طلباً بضغطة واحدة بأسعار اليوم.
- **سير الموافقات الداخلي:** طلب الموظف ينتظر موافقة مسؤول الشركة؛ الرفض يلغي الطلب
  **ويحرّر المخزون المحجوز**.
- **التقارير:** الإيرادات شهرياً بالجنيه والدولار · أفضل العملاء · أكثر المنتجات مبيعاً ·
  تحليل الهامش (بلقطة التكلفة وقت البيع) · أعمار الذمم.
- **طبقة PWA:** غلاف يعمل دون اتصال + **طابور طلبات** يُرسل تلقائياً عند عودة الاتصال.

## ملاحظة تقنية: العربية داخل ملفات PDF

النصيحة الشائعة هي معالجة النص قبل تمريره لمكتبة PDF: تحويل الحروف إلى صورها السياقية
(Presentation Forms) ثم إعادة ترتيبها بصرياً. **هذه النصيحة خاطئة هنا وتُفسد المخرجات.**

pdfmake يرسم عبر pdfkit + fontkit، و**fontkit ينفّذ محرك تشكيل OpenType كاملاً**: يكفي
تمرير النص بترميز Unicode الأصلي ليصل الحروف ويعكس ترتيب المقاطع من اليمين لليسار مع إبقاء
الأرقام والحروف اللاتينية من اليسار لليمين.

قيست البدائل الأربعة فعلياً على المسار الحقيقي:

| المعالجة | النتيجة |
|----------|---------|
| **النص كما هو** | ✅ اتصال صحيح، ترتيب صحيح، والنص يبقى قابلاً للبحث والنسخ |
| إعادة ترتيب bidi | ❌ fontkit يشكّل نصاً معكوساً فتخرج صور سياقية خاطئة |
| تحويل لصور سياقية | ❌ يعتمد على احتواء الخط لها — Cairo ينقصه U+FE8D فظهر U+0000 |

لذلك يُمرَّر النص دون معالجة، ويُستخدم خط **Amiri** لتغطيته الكاملة. للتحقق البصري:
`npm run dev` ثم افتح `/pdfcheck.html` — يولّد كل المستندات ويعرضها كصور عبر pdf.js
(أداة تطوير فقط، غير مضمّنة في بناء الإنتاج).
